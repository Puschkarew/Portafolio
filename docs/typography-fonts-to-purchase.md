# Финальный список шрифтов к покупке

По зеркалу типографики в [styles/tokens.css](../styles/tokens.css) (источник — Figma «Starting Point», `OrSenMzG1cZgmJzjvi7ikP`) для продакшена имеет смысл лицензировать **только эти две гарнитуры**:

1. **American Grotesk** — начертания **Regular (400)** и **Medium (500)**.
2. **Society** — retail-версия вместо **Society Trial** из макетов; минимум **Regular (400)** и **Italic** (курсив обязателен под стиль body italic).

**Не в списке на покупку:** Inter (бесплатный fallback), системные гарнитуры в стеке.

Если в самом Figma-файле появились новые text styles с другими семействами, список может расшириться — тогда ориентируйтесь на панель Text styles в Figma, а не только на текущий `tokens.css`.
